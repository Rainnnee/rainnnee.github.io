LiDAR traffic monitoring

A C++ point-cloud pipeline for grouping vehicles, tracking them across frames, and estimating speed.

Project snapshot

Type
Independent project
Tools
C++ · Linux
Focus
3D point-cloud processing

Pipeline

I implemented a three-dimensional breadth-first-search pipeline to group LiDAR points into vehicles and create bounding boxes around the detected groups.

The pipeline tracks vehicles frame by frame and estimates their speed to support traffic-flow analysis. I’ll add implementation details and visual examples as they’re ready to share.
