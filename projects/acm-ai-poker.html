What we’re building

We’re developing a transformer-based model that learns from sequences of game states and actions. The aim is to estimate the probabilities of folding, calling, or raising using the current situation and the behavior observed earlier.

Where it stands

The project is in progress. This page describes the model we’re working toward; there are no final evaluation results to report yet.
